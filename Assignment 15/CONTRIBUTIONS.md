## Key Takeaway

Open-source contribution is 20% code and 80% communication. The PR that
gets merged is the one with a clear title, a description that explains
*why* not just *what*, a linked issue, and passing CI. The code itself
rarely gets rejected - it is usually the context around it that determines
whether a maintainer has enough confidence to click Merge.
